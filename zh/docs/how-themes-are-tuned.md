# 配色怎么调整

[English](../../docs/how-themes-are-tuned.md) · **简体中文**

本页说明哪些颜色和原主题不同、为什么不同，读完就能预判一套主题的样子。文中的对比度都是颜色与其所在底色之间的 WCAG 对比度。

## 从原主题出发

每套主题都从原样发布的原主题开始。C Dracula Light、C Moka Light 和 C Pale Light 这三套全新浅色设计，先由对应的深色原主题生成，再走同样的步骤。各套主题对应的原主题见[主题一览](themes.md#找到你的原主题)。

## 只补缺失

**补全只加原主题没设的颜色，不改原主题设过的任何颜色。**

- 终端、diff、git 标记等 VS Code 原本写死默认值的界面色，取本主题终端色的色相；上面的字至少和 VS Code 默认配色一样易读；默认配色超过 4.5 时，只要求到 4.5。
- 语法规则来自全部原主题合并的规则池，只补在原主题没上色的 scope 上。
- 有些池内规则会借外层 scope 改掉原主题已上色的 token；生成时对样例文件分词实测，查出这类规则就跳过。
- 括号配对色 1–3 用本主题自己的颜色；4–6 和 VS Code 一样不设。

## 只修看不清的地方

**只改读不清的那一侧，只改到够用，色相与饱和度不变。**

| 对象 | 下限 |
| --- | --- |
| 正文 | 4.5 |
| 语法色 | 4.5 |
| 终端普通色与亮色 | 4.5 |
| 注释 | 3.4 |
| 终端暗灰（`90m`） | 3.4 |
| 选区、查找匹配等高亮底上的正文 | 3.5 |

- 编辑区和输入框选区调到看得出：从原选区色出发，只动必要的一侧。
- 原终端选区几乎看不出，或选区上的字读不清时，用本主题的终端蓝重新计算终端选区。
- 当前查找匹配比其他匹配更醒目。
- 侧栏文字、行号、边框、徽标、按钮、选中行等界面色分为四层：内容、暗化、线条、底色。每层的下限相对本主题正文来定，并用 8 套参考主题标定。半透明的颜色先加不透明度，之后只调明度。

## 压低深色主题里的近纯白

深色主题里 `#FFFFFF` 这类近纯白，压到 OKLCH 明度 0.88，色相不变。涉及正文、界面文字、图标和线条、语法色，以及终端白。例如 C Dracula Dark 的正文从 `#F6F6F4` 变为 `#D7D7D6`，C Ayu Dark、C Owl Dark 和 C Pale Dark 的终端亮白从 `#FFFFFF` 变为 `#D7D7D7`。

## 哪些不动

不换底色，除近纯白外不调暗正文，也不压彩色。
